\# SJU-IOT



\## Sampah Jadi Uang



SJU-IOT adalah sistem \*\*Reverse Vending Machine (RVM) berbasis Internet of Things (IoT)\*\* untuk mendeteksi dan memvalidasi botol plastik secara otomatis serta memberikan \*\*point digital\*\* kepada pengguna.



Sistem ini mengintegrasikan ESP32, ESP32-CAM, YOLO, Sensor Load Cell, Python, CodeIgniter 4, dan MySQL.



\## Fitur Utama



\- Deteksi botol plastik menggunakan YOLO

\- Validasi berat menggunakan Load Cell

\- Komunikasi perangkat menggunakan ESP32

\- Monitoring mesin secara realtime

\- Monitoring sensor

\- Machine session

\- Manajemen pengguna

\- Manajemen transaksi

\- Point digital

\- Dashboard web

\- AI Service berbasis Python
